## 2. Live In The Vineyard XI
**April 4–7, 2013 · Napa Valley, CA**

Private music/food/wine showcase for radio programmers and label staff. Goo Goo Dolls headlined the Uptown Theatre mainstage April 6; that set later aired on SiriusXM.
